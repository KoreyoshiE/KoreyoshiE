# Han

**Data Science Undergraduate**

I work on machine learning, research software and data systems. My public projects focus on traceable data processing, out-of-sample evaluation and clear limits on what the results support.

## Selected research

- **[WDCGG Data Pipeline](https://github.com/KoreyoshiE/wdcgg-data-pipeline)** — Python workflows for acquiring, screening and analysing long-term WDCGG CO₂ and CH₄ observations. The repository includes source manifests, offline tests and frozen result summaries; third-party observations are not redistributed.
- **[Shanghai Ozone ML](https://github.com/KoreyoshiE/shanghai-ozone-ml)** — A 2021–2025 Shanghai ozone study using ERA5 fields, repeated SOM weather typing, leave-one-year-out Random Forest evaluation and out-of-fold SHAP. The public code documents data-access limits and seasonal uncertainty in the weather catalogue.

## Selected projects

- **[Huawei LLM Agent Router](https://github.com/KoreyoshiE/Huawei-LLM-Agent-Router)** — Competition work on Qwen3 tool selection, direct and two-stage prompting, synthetic examples and evaluation. The current code proposes tool calls; it does not execute them.
- **[OmniStream Database Project](https://github.com/KoreyoshiE/OmniStream-Database-System)** — PostgreSQL coursework covering relational design, constraints, JSONB, analytical SQL and transaction handling.
